# Muskan — Portfolio

Personal site for Muskan, a B.Tech CSE student at Thapar Institute of Engineering and Technology. Built as an execution topology: request → system → proof → response.

## Stack

Next.js (App Router) · TypeScript · Tailwind CSS · Framer Motion · GSAP · React Three Fiber

## Run

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Content

All copy, metrics, and links live in `content/content.ts`. Do not invent results. Add real screenshots under `public/screenshots/` and set `src` on each project shot.

## Deploy

Vercel. Set the production domain in `app/layout.tsx` metadataBase, `app/sitemap.ts`, and `app/robots.ts` if it is not `https://muskan.engineering`.
